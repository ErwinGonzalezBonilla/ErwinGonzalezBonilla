## 👨‍💻 Sobre mí

Construyo aplicaciones web con **React y Python** y les integro **IA**: chatbots, agentes y flujos automatizados.

Antes de programar pasé **15+ años gestionando inventario, compras y proveedores** en Venezuela 🇻🇪 y Chile 🇨🇱. Por eso diseño software pensando en cómo trabaja de verdad un negocio.

- 🎯 Busco mi **primer rol como developer**
- 🌱 Preparando **AWS Cloud Practitioner**
- 🗣️ Español nativo · Inglés B1
- ⚡ Dato curioso: gestioné el stock de una tienda durante años; ahora construyo el software que me habría gustado tener

## 🚀 Proyectos

### 📦 [MyStock](https://github.com/ErwinGonzalezBonilla/MyStock) &nbsp;`🚧 en desarrollo`
SaaS multiempresa de **inventario, punto de venta, compras y proveedores**, con un 🤖 asistente de IA que sugiere qué reponer.\
🛠️ React · FastAPI · PostgreSQL · OpenAI · n8n &nbsp;|&nbsp; 🔐 Multi-tenant con JWT

### 🎤 [Kevin Alva · Web y entradas](https://github.com/ErwinGonzalezBonilla/kevin-alva-web) &nbsp;`✅ en producción`
Web oficial de un artista con venta de entradas: 💳 pago con Stripe → 🎟️ entrada con QR firmado → 📱 validación en puerta.\
🛠️ JavaScript · Node.js · Stripe · Vercel &nbsp;|&nbsp; 🌐 [kevinalvamusic.com](https://www.kevinalvamusic.com)

### 🎈 [Ballonette](https://github.com/ErwinGonzalezBonilla/ballonette-react) &nbsp;`✅ cliente real`
Web para una empresa de eventos con 🖼️ galería, 🛠️ panel de administración y 🤖 **BalloonBot**, un chatbot con OpenAI.\
🛠️ React · Vite · Cloudinary · OpenAI &nbsp;|&nbsp; 🌐 [Ver demo](https://ballonette-react.vercel.app)

### 🐾 [Patitas Club](https://github.com/4GeeksAcademy/PatitasClub) &nbsp;`🤝 equipo · 411 commits`
E-commerce para mascotas con API REST en Flask, 🔐 login con JWT y 💳 pagos con Stripe.\
🛠️ React · Flask · SQLAlchemy · Stripe

### 💌 [Generador de invitaciones](https://github.com/ErwinGonzalezBonilla/generador-invitaciones) &nbsp;`🌍 uso público`
✍️ Rellenas los datos → 👀 vista previa en directo → 📲 compartes por WhatsApp. ⚡ Sin backend.\
🛠️ HTML · CSS · JavaScript &nbsp;|&nbsp; 🌐 [Crear invitación](https://generador-invitaciones.vercel.app)

### 🐶 Don Dog · Tienda online &nbsp;`🚧 en desarrollo`
Tienda para un pet shop con 📊 control de stock y 🤖 **"El Don"**, un asistente que recomienda productos según la mascota.
